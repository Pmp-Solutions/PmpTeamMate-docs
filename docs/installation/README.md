# Démarrage et installation

Cette section couvre tout ce dont vous avez besoin pour installer et configurer PMP TeamMate dans votre organisation.

## Vue d'ensemble

L'installation de PMP TeamMate comprend plusieurs étapes importantes pour assurer un déploiement réussi :

1. **Installation du système** - Configuration de l'environnement et déploiement de l'application
2. **Gestion des utilisateurs** - Création et administration des comptes utilisateurs
3. **Configuration des tableaux de bord** - Mise en place des dashboards sur différents dispositifs

## Guides disponibles

### [Installer PMP TeamMate](/installation/install/)
Guide complet pour installer et configurer PMP TeamMate sur votre infrastructure. Vous y trouverez les instructions pour la connexion web et la configuration du serveur.

### [Gestion des utilisateurs](/installation/users/)
Apprenez à créer et gérer les comptes utilisateurs, configurer les accès et les permissions pour votre équipe.

### [Tableaux de bord sur téléviseurs](/installation/dashboards/)
Instructions pour installer et configurer les tableaux de bord PMP TeamMate sur des écrans dédiés pour un suivi visuel en temps réel.

## Prérequis

Avant de commencer l'installation, assurez-vous de disposer de :
- Un accès administrateur à votre système
- Les droits nécessaires pour créer des utilisateurs
- Une connexion réseau stable

## Prochaines étapes

Une fois l'installation terminée, consultez la section [Apprentissage et utilisation](/apprentissage/) pour découvrir comment utiliser efficacement PMP TeamMate.
